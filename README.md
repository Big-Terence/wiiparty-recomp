🎉 Party Game
Un party game multijoueur composé de mini-jeux, inspiré de l'esprit de Wii Party et entièrement recodé à la main dans le cadre d'un projet étudiant.

Le projet est open source et libre : chacun peut le consulter, le modifier et le redistribuer.

🤝 Contribuer
Toutes les contributions sont les bienvenues. Forke le dépôt, fais tes modifications et ouvre une Pull Request. Les bugs et les idées se signalent dans l'onglet Issues.
